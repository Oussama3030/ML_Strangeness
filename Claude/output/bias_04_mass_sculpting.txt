==============================================================================
3. WHAT THE MODEL DOES WHEN IT MEETS REAL DATA
==============================================================================
  Train exactly as the pipeline does (S_MC vs sideband data), then apply the
  model to ALL data, including the mass window it never saw.  The data holds
  no meaningful L* signal at this level, so a healthy model should keep a
  sensible fraction of candidates and NOT change the mass shape.

  -- all 16 features (as trained) --
  fraction of data candidates with P > 0.5 : 0.000034
           working point  threshold  eff outside   eff inside     in/out
           keep top 100%    -1.0000      1.00000      1.00000      1.000
            keep top 10%     0.0027      0.09849      0.10967      1.113
             keep top 1%     0.0202      0.01042      0.00728      0.698
           keep top 0.1%     0.0791      0.00105      0.00068      0.642

             keep top 1%     0.1847      0.00978      0.01145      1.171

  "in/out" is the factor by which the BDT preferentially keeps candidates
